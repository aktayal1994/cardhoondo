# CarDhoondo

AI-powered car recommender for the Indian market. Answer 13 questions about how you actually drive and live, get 2–3 car recommendations backed by real, evidence-quoted review data — no dealer commissions, no sponsored results.

Built with Next.js (App Router) + Tailwind CSS + Supabase.

## Development

```
npm install
npm run dev
```

Requires `.env.local` (see `.env.local.example`) with Supabase and Gemini API credentials.
